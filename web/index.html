Patch supported player firmware files for customization.

Firmware and files are not uploaded and runs locally on the browser using WebAssembly.
Not all external URLs are supported, and the server needs to offer CORS to allow remote download.

FRM file, or the ZIP / EXE as downloaded from Panasonic.
ZIP or YAML format. Not strictly necessary if using other options or downgrading.
Player will start the firmware upgrade or downgrade regardless of installed version. Make sure to remove media after install to prevent a loop.
Player will schedule an HDD format after upgrading. This likely only applies to DVR units.
